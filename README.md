# mdwiki

Local-first knowledge base over ordinary Markdown files. TypeScript, CLI + stdio
MCP, full-text search, backlinks, and filesystem watching. Complements an existing
Obsidian vault; files remain the source of truth.

Status: planning scaffold. The application is not implemented or published yet.
See the [plan](docs/PLAN.md) and [v0.1 specification](docs/features/v0.1/SPEC.md).

Planned runtime: Node.js LTS on macOS and Linux. Planned command: `mdwiki`.
Package registry naming and publication will be verified before release; local
npm tarball installation is part of the acceptance gate.

This is intentionally separate from [mdkb](https://github.com/ContractorKeith/mdkb),
providing a TypeScript learning ground for agent development, review, and testing.
